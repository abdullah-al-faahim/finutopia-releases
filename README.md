# FinUtopia releases

Android builds of **FinUtopia**, an offline-first money tracker for Bangladesh: cash, bKash and
bank accounts, budgets, DPS, FDR, Sanchayapatra, loans and EMIs, and insurance in one app.

## Install

1. Open the [latest release](https://github.com/abdullah-al-faahim/finutopia-releases/releases/latest)
   on your phone and download the `.apk`.
2. Open it and allow your browser to install apps when Android asks.

After that, FinUtopia checks this page itself (Settings → App updates) and installs new versions
over the old one; your data stays on the phone.

The source code is private. This repository only hosts release files.
